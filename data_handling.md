# Data Handling

This evaluation repo uses synthetic workflow packets only.

Do not submit PHI, PII, customer-identifiable data, employee-identifiable data, supplier-confidential terms, trade secrets, credentials, access tokens, material non-public information, raw system exports, or real regulated records.

Workflow packets should use synthetic sample records, fake record IDs, role names rather than person names, generalized policy excerpts, representative field names, and de-identified examples.

The assessment evaluates the submitted workflow packet. It does not verify the live operating process, legal compliance, security posture, or production readiness.
